# FeelFitCentrum

Printbare lesboekjes voor groepslessen aqua.

## Op je telefoon bekijken

1. Open [`index.html`](index.html) in Safari of Chrome op je telefoon.
2. Kies **Aqua Power** of **Aqua Joggen**.
3. Tik bovenaan **01–08** om naar een les te springen, of scroll gewoon.

Handige manieren om de bestanden op je telefoon te krijgen:
- **GitHub Pages** aanzetten op deze repo (Settings → Pages), dan open je de site-URL op je telefoon.
- Of sync de map via iCloud / Google Drive / Files en tik `index.html` aan.
- Op een laptop: knop **Printen** voor het A4-vouwboekje.

## Twee boekjes

| Les | Bad | Open |
|-----|-----|------|
| **Aqua Power** | 1,2–1,5 m · staan · ~schouders | [`aqua-power/index.html`](aqua-power/index.html) |
| **Aqua Joggen** | 1,90 m · band · drijven | [`aqua-joggen/index.html`](aqua-joggen/index.html) |

Start: [`index.html`](index.html) · Lege kaarten in de map van elk boekje.

## Printen

- A4 **liggend**, dubbelzijdig, **omkeer korte zijde**
- 2 lessen per kant → vouwen tot A5-boekje (Les 01–08)

## Lesformule (beide)

WU 5×1′ → Kern1 8×1′×2 → Kern2 8×1′×2 → Buik 5×1′ → CD 5′ · **1 klokslag = 1′**

Doelgroep: 60+ fanatiek · been ↔ arm · Feel Good Classics · DB, noodles, schijven, ballen, aqua barbells
